# 🔁 Leitner 盒子：间隔重复是怎么回事

> 记录时间：2026-07-25

## 问题：为什么不能"背一遍就完事"

人类遗忘遵循**艾宾浩斯遗忘曲线** —— 学完新东西后忘得极快，一天后可能只剩 30%。

但有个关键现象：**每次在"快要忘记"的时刻复习一次，记忆保持时间会显著延长。**

```
只学一次：
记忆强度 ████▓▒░                    → 一周后基本忘光

按间隔复习：
记忆强度 ████▓▒░
         ↑ 复习 ████████▓▒░
                  ↑ 复习 ████████████▓▒░
                            ↑ 复习 ████████████████
```

**间隔重复（Spaced Repetition）** 就是把复习安排在这些关键时刻。

---

## Leitner 盒子：最直观的实现

想象你有 5 个盒子，每张单词卡片放在其中一个：

```
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│ Box 1  │ │ Box 2  │ │ Box 3  │ │ Box 4  │ │ Box 5  │
│ 1 天   │ │ 2 天   │ │ 4 天   │ │ 7 天   │ │ 15 天  │
│        │ │        │ │        │ │        │ │        │
│ 生词/  │ │        │ │        │ │        │ │ 已掌握 │
│ 错词   │ │        │ │        │ │        │ │        │
└────────┘ └────────┘ └────────┘ └────────┘ └────────┘
```

**规则**：

- 新词从 **Box 1** 开始
- 答对 → **升一箱**（到 Box 5 就封顶不动）
- 答错 → **直接掉回 Box 1**（本项目的选择，不是降一箱）
- 每个盒子有自己的复习间隔：Box 3 的词，4 天后才会再出现

**举例**：单词 `accommodate`

| 日期 | 事件 | 盒子变化 | 下次复习 |
|------|------|---------|----------|
| 7/1 | 新词，答对 | 1 → 2 | 7/3（+2天） |
| 7/3 | 答对 | 2 → 3 | 7/7（+4天） |
| 7/7 | **答错**（少了个 m） | 3 → **1** | 7/8（+1天） |
| 7/8 | 答对 | 1 → 2 | 7/10（+2天） |

---

## 为什么"答错掉回 Box 1"而不是"降一箱"

这是个可争议的选择：

| 策略 | 效果 | 感受 |
|------|------|------|
| 掉回 Box 1 | 错词彻底重练 | 严厉，Box 5 错一次要从头来 |
| 降一箱 | 温和调整 | 宽松，但真正的难词可能一直混在高箱 |

本项目**先用"掉回 Box 1"**，理由是：答错说明这个词根本没记牢，重新走一遍流程更保险。

参数写在配置里，用起来觉得挫败感太强随时可以改成"降两箱"。而且因为有[事件溯源](./05-event-sourcing.md)，改完重放一遍就能重建全部历史进度。

## 和 SM-2（Anki 算法）的区别

Anki 用的是 **SM-2**，更精细：

| | Leitner | SM-2 |
|---|---------|------|
| 要存的状态 | `box`（1 个整数） | `ease_factor` + `interval` + `repetitions`（3 个字段） |
| 复习间隔 | 固定档位（1/2/4/7/15） | 动态计算，每个词不同 |
| 用户反馈 | 只有对/错 | 分 4 档（完全忘了 / 困难 / 一般 / 简单） |
| 复杂度 | 低 | 中 |

**本项目选 Leitner**：状态只有一个整数，逻辑简单到不会写错，对新手足够有效。

将来想换 SM-2？因为有完整的答题事件历史，重放一遍就能重建进度，不丢数据。

## 代码长什么样

核心逻辑就这几行（**必须是纯函数**，这样才能重放）：

```python
BOX_INTERVALS = {1: 1, 2: 2, 3: 4, 4: 7, 5: 15}  # 天

def apply_answer(box: int, is_correct: bool, answered_at: datetime):
    """输入当前盒子号 + 这次答对没，输出新盒子号 + 下次复习时间。"""
    if is_correct:
        new_box = min(box + 1, 5)      # 升一箱，封顶 5
    else:
        new_box = 1                     # 答错直接回 Box 1

    next_review = answered_at + timedelta(days=BOX_INTERVALS[new_box])
    return new_box, next_review
```

> **"纯函数"** 的意思是：同样的输入永远得到同样的输出，不依赖外部状态、不修改任何东西。
> 这很重要 —— 只有纯函数才能拿一堆历史事件反复重放，每次都得到相同结果。
