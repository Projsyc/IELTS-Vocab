# 📖 learning-docs 学习笔记

> 这里放**概念扫盲**笔记，写给编程初学者。
> 和 [`../docs/`](../docs/) 的区别：docs 是"项目是怎样的"，这里是"这些概念是什么意思"。

## 笔记列表

| # | 笔记 | 一句话 | 什么时候看 |
|---|------|--------|-----------|
| 01 | [pnpm 是什么](./01-what-is-pnpm.md) | 更快更省磁盘的包管理工具 | 看到 `pnpm install` 一脸懵时 |
| 02 | [Monorepo 是什么](./02-what-is-monorepo.md) | 前后端代码放同一个仓库 | 好奇为什么目录这么分时 |
| 03 | [技术选型决策](./03-tech-stack-decision.md) | 为什么选 React/FastAPI/PostgreSQL | 想知道"为啥不用 Vue"时 |
| 04 | [Leitner 间隔重复算法](./04-leitner-algorithm.md) | 5 个盒子安排复习节奏 | 写背诵算法前 |
| 05 | [事件溯源](./05-event-sourcing.md) ⭐ | 存"发生了什么"而非"现在怎样" | **动进度相关代码前必读** |

## 阅读建议

**如果你刚接触这个项目**，按顺序看 01 → 02 → 03，理解项目怎么组织的。

**如果你要开始写代码**，重点看 04 和 05 —— 这两个是本项目的核心机制，不理解会写错。

## 写笔记的约定

- 用**大白话**，假设读者不知道任何术语
- 多画图（ASCII 图就行），少堆概念
- 每篇结尾用 `[[笔记名]]` 链接相关笔记
- 涉及项目具体实现时，链接到对应的 `docs/` 文档
