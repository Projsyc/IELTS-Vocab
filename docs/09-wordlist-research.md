# 09 词库数据源调研报告

> 调研日期：2026-07-25 · 状态：✅ 已完成，结论已采纳
> 对应路线图：[M1 数据地基](./05-roadmap.md) 第一项（标记为 🔴 最大未验证风险）

---

## 结论速览

**风险解除。** ECDICT 自带 `ielts` 考试标签，直接提供 5,040 个雅思词，MIT 许可 —— 版权问题一并消失，不再需要从受版权保护的出版物提取词表。

音频和音标从 dictionaryapi.dev 获取，缺口用 edge-tts 和清洗版 ECDICT 兜底，最终 **100% 有音频、100% 有音标**。

唯一仍需自建的是**雅思话题标签**（用于阅读模式干扰项），任何现成数据源都没有这个字段。

## 1. 词表与释义：ECDICT

**来源**：[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT) · **许可**：MIT · **规模**：770,611 词条

### 1.1 关键发现：自带考试标签

ECDICT 的 `tag` 字段标注了词条属于哪些考试大纲。实测全库标签分布：

| 标签 | 含义 | 词条数 |
|------|------|--------|
| `gre` | GRE | 7,504 |
| `toefl` | 托福 | 6,974 |
| `cet6` | 六级 | 5,407 |
| **`ielts`** | **雅思** | **5,040** |
| `ky` | 考研 | 4,801 |
| `cet4` | 四级 | 3,849 |
| `gk` | 高考 | 3,677 |
| `zk` | 中考 | 1,603 |

**这直接替代了对《刘洪波雅思词汇真经》的需求** —— 不必从受版权保护的出版物提取词表。

### 1.2 ielts 子集（5,040 词）字段完整度

| 字段 | 完整度 | 可用性 |
|------|--------|--------|
| `word` | 100% | ✅ |
| `translation` 中文释义 | 100% | ✅ |
| `definition` 英文释义 | 99.6% | ✅ 备用 |
| `phonetic` 音标 | 95.1% | ⚠️ 非标准记法，见 §3 |
| `bnc` / `frq` 词频 | 100% | ✅ 用于难度分级 |
| `collins` 星级 | 85.0% | ✅ 备用难度信号 |
| `exchange` 词形变化 | 84.5% | 暂不使用 |
| `pos` 词性 | **0%** | ❌ 字段全空，但可从释义前缀解析（见下） |
| `audio` 音频 | **0%** | ❌ 字段全空 |
| `detail` 例句 | **0%** | ❌ 字段全空 |
| **话题分类** | **字段不存在** | ❌ 必须自建 |

### 1.3 词性可从释义前缀解析

`pos` 字段虽空，但 `translation` 以词性缩写开头，**99.5% 可解析**：

```
abbreviation  →  "n. 缩写词, 缩写, 缩短, 节略"           →  n.
abnormal      →  "a. 反常的, 不规则的, 变态的, 畸形的"    →  a.
abolish       →  "vt. 废止, 革除, 消灭"                  →  vt.
```

前缀分布：`n.`(3399) `a.`(874) `vt.`(473) `vi.`(103) `v.`(83) `adv.`(49) `pl.`(11) `prep.`(9) `abbr.`(6) `num.`(3)

### 1.4 一词多义：75.1%

多义项在 `translation` 里用**字面 `\n`**（反斜杠+n 两个字符，非真换行）分隔。

| 指标 | 值 |
|------|-----|
| 含多义项的词 | 3,783 / 5,040（75.1%） |
| 平均义项数 | 2.06 |
| 最多义项数 | 6 |

**长度对比**（决定阅读模式选项如何呈现）：

| | 中位数 | 最长 | 超 40 字占比 |
|---|---|---|---|
| 完整释义 | 27 字 | 169 字 | — |
| 仅第一义项 | **14 字** | 83 字 | **1.6%** |

示例：

```
abstract
  完整: a. 抽象的, 深奥的 ／ n. 摘要, 抽象概念 ／ vt. 摘要, 提炼, 使抽象化 ／ [计] 摘录; 摘要; 抽象   (61 字)
  首义: a. 抽象的, 深奥的                                                                        (11 字)
```

第一义项确实是主要词义，且长度均匀 —— 适合做 4 选 1 的选项。完整释义太长且长度差异大，**长选项本身会泄露答案**。

## 2. 音频：dictionaryapi.dev + edge-tts

### 2.1 实测结果

**[dictionaryapi.dev](https://dictionaryapi.dev/)** —— 免费、无需 API key

| 指标 | 实测值 | 样本 |
|------|--------|------|
| 词条命中率 | 96% | 25 词随机抽样 |
| **有音频比例** | **70–76%** | 两轮抽样 |
| 音频托管主机 | `api.dictionaryapi.dev`（100%） | 20 词抽样 |
| 下载延迟中位数 | **760 ms** | 最慢 938 ms |
| 单词音频大小 | ~23 KB | accommodate 实测 |

缺音频的词包含常见词：`cafeteria` `classify` `underground` `audible` `charity` `technician`

**760ms 延迟意味着热链不可用** —— 听写时点"播放"要等近 1 秒，体验不可接受。且音频 100% 来自单一免费社区服务，热链既慢又是单点故障，还会骚扰对方。

**[edge-tts](https://github.com/rany2/edge-tts)** —— 实测可用

```
en-GB-SoniaNeural  →  10,656 bytes  ✅
en-US-AriaNeural   →  11,088 bytes  ✅
```

### 2.2 采纳方案

```
76% → dictionaryapi.dev 真人发音，seed 阶段下载到本地
24% → edge-tts 合成，seed 阶段生成到本地
────────────────────────────────────────────
100% 覆盖，全部本地文件，播放零延迟
```

预估存储：5,040 × ~20 KB ≈ **100 MB**（不进 git）

### 2.3 许可状况（诚实记录）

| 来源 | 许可状况 |
|------|---------|
| dictionaryapi.dev 音频 | 免费社区服务，无明确再分发许可。本地缓存自用风险低 |
| edge-tts | 库本身 LGPL-3.0；但微软那个 TTS 端点**没有公开的开发者协议**，缓存/再分发法律地位模糊 |
| Wikimedia Commons | CC 许可，唯一可安全再分发，但覆盖率低（未详测） |

**结论**：MVP 本地自用风险可接受。**v2 公网部署前必须复核** —— 届时若判定不可行，可退回浏览器 `SpeechSynthesis` 实时合成（改动量：一个字段判空 + 前端降级分支）。

## 3. 音标：改用 dictionaryapi.dev

### 3.1 ECDICT 音标的问题

**问题一：混入西里尔字母**

| 字符 | Unicode | 出现次数 | 说明 |
|------|---------|---------|------|
| `ә` | U+04D9 | 3,201 | **CYRILLIC SMALL LETTER SCHWA** —— 应为 IPA `ə` (U+0259) |
| `є` | U+0454 | 57 | **CYRILLIC SMALL LETTER UKRAINIAN IE** —— 应为 IPA `ɛ` (U+025B) |

影响 **2,490 / 5,040（49.4%）** 词条。其余符号（`ɒ æ ʃ ʌ ʒ ŋ ɑ θ` 等）都是合法 IPA。

**问题二：整套记音体系不是现代 IPA**

尝试用规则规范化后，与标准 IPA 对照 **0/8 一致**：

| 词 | ECDICT | 规则转换后 | 标准 IPA | |
|---|---|---|---|---|
| ability | `ә'biliti` | `/əˈbiliti/` | `/əˈbɪlɪti/` | ❌ |
| accommodate | `ә'kɒmәdeit` | `/əˈkɒmədeit/` | `/əˈkɒmədeɪt/` | ❌ |
| environment | `in'vairәnmәnt` | `/inˈvairənmənt/` | `/ɪnˈvaɪrənmənt/` | ❌ |
| photograph | `'fәutәgrɑ:f` | `/ˈfəutəgrɑːf/` | `/ˈfəʊtəɡrɑːf/` | ❌ |

系统性差异：

| ECDICT | 标准 IPA |
|--------|---------|
| `i` | `ɪ` |
| `ei` | `eɪ` |
| `ai` | `aɪ` |
| `әu` | `əʊ` |
| `ɒ:` | `ɔː` |
| `g` | `ɡ` (U+0261) |

**关键障碍**：单个 `i` 无法从字符判断该是 `ɪ` 还是 `i` —— 取决于具体单词，规则替换做不到。**"完全规范化成标准 IPA"这条路走不通。**

### 3.2 采纳方案：从 dictionaryapi.dev 取

实测 **96% 覆盖，返回真正的标准 IPA**：

| 词 | dictionaryapi.dev | ECDICT |
|---|---|---|
| thoughtful | `/ˈθɔːtfəl/` | `'θɒ:tful` |
| representative | `/ˌɹɛpɹɪˈzɛnt(ət)ɪv/` | `.repri'zentәtiv` |
| upright | `/ˈʌpɹaɪt/` | `'ʌprait` |

**零额外成本** —— seed 阶段本来就要为每个词调这个 API 拿音频，音标顺手取。

**两点处理**：
- API 用 `ɹ` (U+0279 turned r)，归一化为 `r`（学习者更熟悉）
- 缺失的 4% 用清洗版 ECDICT 兜底：`ә→ə` `є→ɛ` `'→ˈ` `.→ˌ` `:→ː`
  （`.` 经比对确认是**次重音标记**：`.æbә'ridʒәnәl` → `/ˌæbəˈrɪdʒənəl/`）

## 4. 话题标签：必须自建

**没有任何现成数据源提供雅思话题分类。**

- ECDICT 无此字段
- GitHub 搜索 "ielts vocabulary topic category" → **0 个结果**

这是阅读模式干扰项质量的命根子（见 [ADR-003](./08-decisions.md)），只能用 LLM 批量打标，并抽样人工校验。

---

## 5. 选词策略

**决定：5,040 词全部导入，并存下考试标签。**

5,040 个 ielts 词与其他考试大纲的重叠：

| 标签 | 重叠数 | 占比 |
|------|--------|------|
| cet6 六级 | 3,042 | 60.4% |
| ky 考研 | 3,058 | 60.7% |
| toefl 托福 | 2,911 | 57.8% |
| cet4 四级 | 2,146 | 42.6% |
| gre GRE | 2,114 | 41.9% |
| gk 高考 | 1,713 | 34.0% |
| zk 中考 | 641 | 12.7% |

排除中考/高考/四级后剩 2,316 词。

**为什么全导入**：
1. 导入不做取舍，"练哪些"变成应用层的筛选器（可选"跳过四级词"）—— 更灵活且零成本
2. Leitner 会自动把简单词推进 Box 5 不再出现，不浪费练习时间
3. 换筛选条件不用重跑 seed

**为什么不按词频取前 4000**：BNC 词频前列是 `in` `on` `say` `as` `get` —— 雅思考生不需要背这些。纯频率排序会让最没价值的词排最前，同时挤掉真正该学的难词。

## 6. 采纳的 seed 流程

```
1. 从 ecdict.csv 筛 tag 含 ielts               →  5,040 条
2. 解析词性（translation 前缀）                 →  99.5%
3. 拆分完整释义 / 首义                          →  100%
4. 逐词调 dictionaryapi.dev                     →  IPA 96% + 音频 76%
   ├─ 下载音频 MP3 到本地
   └─ 提取 IPA，ɹ→r 归一化
5. 无音频的 24% → edge-tts 生成                 →  音频补至 100%
6. 无音标的 4%  → 清洗版 ECDICT 兜底            →  音标补至 100%
7. LLM 批量打雅思话题标签 → 抽样人工校验         →  自建
```

**已知成本**：
- 第 4 步约 **75 分钟**（5,040 词 × ~0.9s；需限速避免骚扰免费服务，可并发缩短）
- 音频约 **100 MB**（不进 git）

**工程要求**：
- seed 脚本必须**可断点续跑**（75 分钟的流程中断了不能从头来）
- 对 dictionaryapi.dev 限速 + 失败重试
- 记录每个词的数据来源，方便日后排查

## 7. 复现方式

本报告所有数字均为实测，可复现：

```bash
curl -sL -o /tmp/ecdict.csv \
  https://raw.githubusercontent.com/skywind3000/ECDICT/master/ecdict.csv
# 筛选 tag 含 ielts 的行后统计各字段完整度
```

调研中使用的临时环境（`/tmp/ecdict`、`/tmp/ttstest`）为一次性，未纳入仓库。

## 8. 遗留风险

| 风险 | 等级 | 应对 |
|------|------|------|
| LLM 话题标签质量未验证 | 🟡 | seed 第 7 步后抽样人工校验 |
| dictionaryapi.dev 是免费社区服务，可能限流或下线 | 🟡 | seed 时限速重试；音频已本地化，服务下线不影响已导入数据 |
| 音频文件许可（edge-tts / dictionaryapi.dev） | 🟡 | 本地自用可接受；**v2 部署前必须复核**，退路是浏览器 TTS |
| ECDICT 释义偏简略、部分带 `[计]`/`[经]` 领域标记 | 🟢 | 可接受；必要时清洗领域标记 |
