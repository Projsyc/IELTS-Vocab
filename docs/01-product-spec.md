# 01 产品需求说明书（PRD）

> 版本：v0.1 · 最后更新：2026-07-25
> 需求来源：2026-07-25 grilling session

---

## 1. 产品定位

一个**雅思单词记忆应用**，参考[同桌英语单词听写板块](https://ielts.itongzhuo.com/business/ielts/student/jumpAnswerWordDictation.do?sSubjects=0&leftType=1)的核心玩法，加入间隔重复算法和多端进度同步。

**目标用户**：作者本人 + 小范围朋友（预计 5–30 人）
**不是什么**：不是商业产品，不追求大规模用户、不做付费体系、不做社交功能。

---

## 2. 核心玩法

### 2.1 两种练习模式

#### 模式 A：听写模式（Dictation）

```
┌─────────────────────────────────┐
│  🔊 [播放发音]  （可重播）        │
│                                 │
│  请拼写你听到的单词：             │
│  ┌───────────────────────────┐  │
│  │ ______                    │  │
│  └───────────────────────────┘  │
│                    [提交 Enter] │
└─────────────────────────────────┘
```

**流程**：播放音频 → 用户键盘拼写 → 提交 → 判对错 → 展示结果 → 下一个

**判定规则**：**严格匹配，但标出错处**
- 忽略：首尾空格、大小写
- 不容错：差一个字母即判错
- 判错时高亮显示错误位置，例如：

  ```
  你的答案：a c c o m ᵐ o d a t e     ← 少了一个 m
  正确答案：a c c o m m o d a t e
                    ↑
  ```

#### 模式 B：阅读模式（Recognition）

```
┌─────────────────────────────────┐
│         accommodate             │
│         /əˈkɒmədeɪt/            │
│                                 │
│  1. 容纳；提供住宿               │
│  2. 加速；促进                   │
│  3. 积累；累积                   │
│  4. 陪同；伴随                   │
│                                 │
│  [1] [2] [3] [4]   [不知道 空格] │
└─────────────────────────────────┘
```

**流程**：展示单词 → 4 个中文释义选项 → 键盘 `1`/`2`/`3`/`4` 或鼠标点选（或按空格选"不知道"）→ 判对错 → 下一个

**干扰项生成**：从**同一雅思话题分类**内随机抽取 3 个其他单词的释义
- 为什么不全库随机：`apple` 配 `量子力学` 这种干扰项毫无区分度，题就白做了
- "不知道"按钮：等同于答错，但不影响用户心态（比乱猜好，数据也更真实）

### 2.2 间隔重复算法（Leitner 盒子）

错词与生词通过 **Leitner 5 盒子系统**安排复习：

| 盒子 | 复习间隔 | 含义 |
|------|----------|------|
| Box 1 | 1 天 | 新词 / 刚答错的词 |
| Box 2 | 2 天 | 答对 1 次 |
| Box 3 | 4 天 | 答对 2 次 |
| Box 4 | 7 天 | 答对 3 次 |
| Box 5 | 15 天 | 已掌握 |

**升降规则**：
- 答对 → 升一箱（Box 5 已是顶格，保持）
- 答错 → **直接掉回 Box 1**（不是降一箱）

> 参数写在配置文件里，可随时调整。详见 [`learning-docs/04-leitner-algorithm.md`](../learning-docs/04-leitner-algorithm.md)

### 2.3 进度独立性

**同一个单词，在两种模式下的进度完全独立。**

> **为什么**："认得出"和"会拼写"是两种不同能力。你可能一眼认出 `accommodate` 是"容纳"，但让你拼出来会少个 `m`。合并成一个进度会互相污染。
>
> **代价**：进度表主键是 `(用户, 单词, 模式)` 三元组，数据量翻倍。可接受。

## 3. 练习入口

### 3.1 每日任务（默认入口）

系统自动挑选今天该练的词：

```
今日任务
├── 到期复习词：按 Leitner 到期时间挑（优先级最高）
└── 新词：补足到每日目标数量
```

用户点"开始"即可，不需要做任何选择。

### 3.2 自由练习

用户自选：词库 → 模式 → 数量 → 开练。

给想突击某个话题、或想多练的用户用。

## 4. 词库

### 4.1 MVP 词库

- **规模**：约 4000 词
- **选词参考**：《刘洪波雅思词汇真经》词表范围
- **释义来源**：开源词典（ECDICT 等），**不直接使用出版物的释义文本**（见 §7 风险）
- **话题标签**：用 LLM 批量打标（教育 / 环境 / 科技 / 健康 / 文化 / 商业 / …）

### 4.2 音频策略（混合式）

| 词库来源 | 音频方案 |
|----------|----------|
| 内置词库 | 后端预生成（Edge-TTS 等）并缓存为音频文件，音质好、多端一致、可离线 |
| 用户上传词库（v2） | 降级为浏览器 `SpeechSynthesis` 实时合成 |

### 4.3 用户自定义词库（v2，不在 MVP）

延后原因：涉及文件上传、CSV 解析、格式校验、错误提示、词库权限（私有/共享）、以及上传词无音频的降级处理 —— 工作量远大于表面。

## 5. 账号与同步

### 5.1 登录方式

- **MVP**：用户名 + 密码（邀请制，作者手动开号）
  - 不做邮箱验证、找回密码、验证码 —— 小范围使用不值得
- **预留**：数据库账号表预留微信 `openid` / `unionid` 字段，为后续微信小程序一键登录留位

### 5.2 多端进度同步（混合式事件溯源）

**核心设计**：

```
answer_events 表（只追加，不修改）        progress 表（缓存，可重算）
┌──────────────────────────┐            ┌─────────────────────┐
│ 用户 / 单词 / 模式        │  ──回放──> │ 用户 / 单词 / 模式   │
│ 对错 / 时间戳 / 设备ID    │            │ 当前盒子号           │
└──────────────────────────┘            │ 下次复习日期         │
       ↑ 每次答题追加一条                 └─────────────────────┘
                                                ↑ 平时直接读这个（快）
```

- **平时**：读 `progress` 表，快
- **多端冲突时**：从 `answer_events` 按时间戳回放重算，结果确定且正确
- **附赠**：完整答题历史 → 可以免费做学习统计、错题回顾、进度曲线

> 这是整个项目最重的架构决定。决策过程见 [`08-decisions.md#adr-002`](./08-decisions.md)

## 6. 明确不做（MVP 范围外）

| 功能 | 为什么不做 | 何时考虑 |
|------|-----------|---------|
| 用户上传词库 | 工作量大，非核心 | v2 |

| 付费 / 会员 | 不是产品目标 | 不做 |
| 例句 / 词根词缀 / 联想记忆 | 先做好核心两个模式 | 待定 |

## 7. 已知风险

### 7.1 版权风险 ⚠️

**问题**：《刘洪波雅思词汇真经》是受版权保护的出版物。

- **词表本身**（收录了哪些单词）：属于事实性内容，版权保护较弱
- **中文释义、例句、编排顺序**：属于受保护的表达，**不能直接复制**

**应对**：
- ✅ 用该书的**选词范围**作为参考（哪些词值得背）
- ✅ 释义从开源词典获取（ECDICT — MIT 协议，77 万词条，含音标释义）
- ❌ 不导入书中的释义文本、例句、章节编排

### 7.2 话题标签质量

LLM 批量打标可能出错（如把 `bank` 标成"环境"而非"商业"）。
**应对**：抽样人工校验；数据库保留 `topic` 可手动修正。

### 7.3 TTS 音频合规

Edge-TTS 等服务的使用条款需确认是否允许缓存音频文件。
**应对**：MVP 阶段本地使用风险低；公网部署前需复核。

## 8. 验收标准（MVP Done 的定义）

- [ ] 能用用户名密码登录
- [ ] 内置 4000 词，含释义、音标、话题标签、发音音频
- [ ] 听写模式：能播音频、能拼写、严格判对错、错误处高亮
- [ ] 阅读模式：能出 4 选 1、干扰项来自同话题、支持键盘 1234 和空格
- [ ] 每次答题写入 `answer_events` 表
- [ ] Leitner 盒子正确升降，"每日任务"能挑出到期词
- [ ] 支持"自由练习"选词库开练
- [ ] 刷新页面 / 换浏览器登录，进度不丢
