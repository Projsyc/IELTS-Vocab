# 01 产品需求说明书（PRD）

> 版本：v0.1 · 最后更新：2026-07-25
> 需求来源：2026-07-25 grilling session

---

## 1. 产品定位

一个**雅思单词记忆应用**，参考[同桌英语单词听写板块](https://ielts.itongzhuo.com/business/ielts/student/jumpAnswerWordDictation.do?sSubjects=0&leftType=1)的核心玩法，加入间隔重复算法和多端进度同步。

**目标用户**：作者本人 + 小范围朋友（预计 5–30 人）
**不是什么**：不是商业产品，不追求大规模用户、不做付费体系、不做社交功能。

---

## 2. 核心玩法

### 2.1 两种练习模式

#### 模式 A：听写模式（Dictation）

```
┌─────────────────────────────────┐
│  🔊 [播放发音]  （可重播）        │
│                                 │
│  请拼写你听到的单词：             │
│  ┌───────────────────────────┐  │
│  │ ______                    │  │
│  └───────────────────────────┘  │
│                    [提交 Enter] │
└─────────────────────────────────┘
```

**流程**：播放音频 → 用户键盘拼写 → 提交 → 判对错 → 展示结果 → 下一个

**判定规则**：**严格匹配，但标出错处**
- 忽略：首尾空格、大小写
- 不容错：差一个字母即判错
- 判错时高亮显示错误位置，例如：

  ```
  你的答案：a c c o m ᵐ o d a t e     ← 少了一个 m
  正确答案：a c c o m m o d a t e
                    ↑
  ```

#### 模式 B：阅读模式（Recognition）

```
┌─────────────────────────────────┐
│         accommodate             │
│         /əˈkɒmədeɪt/            │
│                                 │
│  1. 容纳；提供住宿               │
│  2. 加速；促进                   │
│  3. 积累；累积                   │
│  4. 陪同；伴随                   │
│                                 │
│  [1] [2] [3] [4]   [不知道 空格] │
└─────────────────────────────────┘
```

**流程**：展示单词 → 4 个中文释义选项 → 键盘 `1`/`2`/`3`/`4` 或鼠标点选（或按空格选"不知道"）→ 判对错 → 下一个

**干扰项生成**：从**同一雅思话题分类**内随机抽取 3 个其他单词的释义
- 为什么不全库随机：`apple` 配 `量子力学` 这种干扰项毫无区分度，题就白做了
- "不知道"按钮：等同于答错，但不影响用户心态（比乱猜好，数据也更真实）

### 2.2 间隔重复算法（Leitner 盒子）

错词与生词通过 **Leitner 5 盒子系统**安排复习：

| 盒子 | 复习间隔 | 含义 |
|------|----------|------|
| Box 1 | 1 天 | 新词 / 刚答错的词 |
| Box 2 | 2 天 | 答对 1 次 |
| Box 3 | 4 天 | 答对 2 次 |
| Box 4 | 7 天 | 答对 3 次 |
| Box 5 | 15 天 | 已掌握 |

**升降规则**：
- 答对 → 升一箱（Box 5 已是顶格，保持）
- 答错 → **直接掉回 Box 1**（不是降一箱）

> 参数写在配置文件里，可随时调整。详见 [`learning-docs/04-leitner-algorithm.md`](../learning-docs/04-leitner-algorithm.md)

### 2.3 进度独立性

**同一个单词，在两种模式下的进度完全独立。**

> **为什么**："认得出"和"会拼写"是两种不同能力。你可能一眼认出 `accommodate` 是"容纳"，但让你拼出来会少个 `m`。合并成一个进度会互相污染。
>
> **代价**：进度表主键是 `(用户, 单词, 模式)` 三元组，数据量翻倍。可接受。

## 3. 练习入口

### 3.1 每日任务（默认入口）

系统自动挑选今天该练的词：

```
今日任务
├── 到期复习词：按 Leitner 到期时间挑（优先级最高）
└── 新词：补足到每日目标数量
```

用户点"开始"即可，不需要做任何选择。

### 3.2 自由练习

用户自选：词库 → 模式 → 数量 → 开练。

给想突击某个话题、或想多练的用户用。

## 4. 词库

### 4.1 MVP 词库

- **规模**：**5,040 词**（[ECDICT](https://github.com/skywind3000/ECDICT) 中 `tag` 含 `ielts` 的全部词条）
- **许可**：MIT —— 可自由使用和再分发
- **释义来源**：ECDICT `translation` 字段，100% 覆盖
- **音标**：dictionaryapi.dev 的标准 IPA（96%）+ 清洗版 ECDICT 兜底（4%）
- **话题标签**：用 LLM 批量打标（教育 / 环境 / 科技 / 健康 / 文化 / 商业 / …）—— 无现成数据源

> 📄 数据源实测结果见 [09 词库数据源调研](./09-wordlist-research.md)

**全部导入而非筛选**：`exam_tags` 字段保留 `zk gk cet4 cet6 ky toefl gre` 标签，"练哪些"由应用层筛选（可选"跳过四级词"）。Leitner 也会自动把简单词推进 Box 5 不再出现。见 [ADR-007](./08-decisions.md)。

### 4.2 音频策略

seed 阶段**全部下载到本地**，播放零延迟：

| 来源 | 覆盖 | 说明 |
|------|------|------|
| dictionaryapi.dev | 76% | 真人发音，音质最好 |
| edge-tts | 24% | 神经网络合成，补齐缺口 |
| **合计** | **100%** | 约 100 MB，不进 git |

> 热链方案已排除：实测中位延迟 **760ms**，听写时点"播放"要等近 1 秒，核心交互被毁。
> 用户自定义上传的词库（v2）仍降级为浏览器 `SpeechSynthesis` 实时合成。

### 4.3 用户自定义词库（v2，不在 MVP）

延后原因：涉及文件上传、CSV 解析、格式校验、错误提示、词库权限（私有/共享）、以及上传词无音频的降级处理 —— 工作量远大于表面。

## 5. 账号与同步

### 5.1 登录方式

- **MVP**：用户名 + 密码（邀请制，作者手动开号）
  - 不做邮箱验证、找回密码、验证码 —— 小范围使用不值得
- **预留**：数据库账号表预留微信 `openid` / `unionid` 字段，为后续微信小程序一键登录留位

### 5.2 多端进度同步（混合式事件溯源）

**核心设计**：

```
answer_events 表（只追加，不修改）        progress 表（缓存，可重算）
┌──────────────────────────┐            ┌─────────────────────┐
│ 用户 / 单词 / 模式        │  ──回放──> │ 用户 / 单词 / 模式   │
│ 对错 / 时间戳 / 设备ID    │            │ 当前盒子号           │
└──────────────────────────┘            │ 下次复习日期         │
       ↑ 每次答题追加一条                 └─────────────────────┘
                                                ↑ 平时直接读这个（快）
```

- **平时**：读 `progress` 表，快
- **多端冲突时**：从 `answer_events` 按时间戳回放重算，结果确定且正确
- **附赠**：完整答题历史 → 可以免费做学习统计、错题回顾、进度曲线

> 这是整个项目最重的架构决定。决策过程见 [`08-decisions.md#adr-002`](./08-decisions.md)

## 7. 已知风险

### 7.1 ~~版权风险~~ ✅ 已解除

**原问题**：计划以《刘洪波雅思词汇真经》为选词参考，但该书受版权保护。

**已解决**：改用 [ECDICT](https://github.com/skywind3000/ECDICT)（**MIT 许可**）自带的 `ielts` 考试标签，直接得到 5,040 个雅思词。不再需要从受版权保护的出版物提取任何内容。见 [ADR-007](./08-decisions.md)。

### 7.2 话题标签质量

LLM 批量打标可能出错（如把 `bank` 标成"环境"而非"商业"）。
调研确认**没有任何现成数据源提供雅思话题分类**，只能自建。
**应对**：抽样人工校验；数据库保留 `topic` 可手动修正。

### 7.3 音频许可 ⚠️

两个音频来源的再分发权都不明确：

- **dictionaryapi.dev** —— 免费社区服务，无明确再分发许可
- **edge-tts** —— 库本身 LGPL-3.0，但微软那个 TTS 端点**没有公开的开发者协议**

**应对**：MVP 本地自用风险可接受。**v2 公网部署前必须复核**；若判定不可行，退回浏览器 `SpeechSynthesis` 实时合成（改动量：一个字段判空 + 前端降级分支）。

### 7.4 seed 流程耗时

第 4 步逐词调 API 约 **75 分钟**（5,040 词 × ~0.9s，需限速避免骚扰免费服务）。
**应对**：seed 脚本必须支持**断点续跑** + 失败重试。

## 8. 验收标准（MVP Done 的定义）

- [ ] 能用用户名密码登录
- [ ] 内置 5,040 词，含完整释义、首义、IPA 音标、话题标签、本地音频
- [ ] 听写模式：能播音频、能拼写、严格判对错、错误处高亮
- [ ] 阅读模式：能出 4 选 1、干扰项来自同话题、支持键盘 1234 和空格
- [ ] 每次答题写入 `answer_events` 表
- [ ] Leitner 盒子正确升降，"每日任务"能挑出到期词
- [ ] 支持"自由练习"选词库开练
- [ ] 刷新页面 / 换浏览器登录，进度不丢
